# PyPdfWriter

This is a sample project created to demonstrate how easily Python can translate spreadsheet data to fillable PDF forms. While the source is as arbitrary as the form itself, a similar process could be used to update documents from any number of sources including: text/.csv, databases, websites, and more.

Other notable applications may include:
- drafting original PDF files
- creating a compilation of PDF documents
- applying watermarks, redactions, or other alterations
- reading, processing, or extracting PDF file data

## How To Use

1. Pull the code sample using git: `git clone https://github.com/chmbrb/PyPdfWriter.git`
2. Enter the root project directory: `cd PyPdfWriter`
3. Install the required dependencies using pipenv: `pipenv install`
4. Activate the virtual environment: `pipenv shell`
5. Run the code in app/main.py: `python -m app.main`
